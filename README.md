# AI Resume Builder

A single-page, ATS-friendly Resume Builder web application with real-time resume preview, Job Description analysis, ATS keyword matching, JSON import/export, and PDF generation.

## 🚀 Live Demo

https://vetri2552.github.io/

## ✨ Features

- Real-time resume preview
- Personal details management
- Skills management
- Education section
- Experience section
- Projects section
- Job Description Analyzer
- ATS keyword matching
- Bullet-point suggestions
- Import resume data from JSON
- Export resume data to JSON
- Print / Save resume as PDF
- Single-page resume format
- Responsive web interface
- Works directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser APIs
- GitHub Pages

## 📊 ATS Resume Analysis

The Job Description Analyzer extracts important keywords from a job description and compares them with the resume content to provide an estimated ATS match.

## 📄 PDF Generation

Users can generate a professional one-page resume using the browser's Print / Save as PDF functionality.
